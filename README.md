# Cinema Ticket Booking and Billing System

## About the Project
An OOP-based Cinema Ticket Booking and Billing System developed using C++.

## Features
- Movie details
- Customer booking
- Regular, Premium and VIP seats
- Ticket price calculation
- Billing
- File handling
- Save and read booking records

## OOP Concepts Used
- Classes and Objects
- Constructors
- Inheritance
- Multilevel Inheritance
- Encapsulation
- File Handling

## Technologies Used
- C++
- Object-Oriented Programming
- File Handling

## Seat Types
| Seat Type | Price |
|---|---:|
| Regular | Rs. 150 |
| Premium | Rs. 250 |
| VIP | Rs. 400 |

## How to Run
Compile and run `CinemaTicketBilling.cpp`.
